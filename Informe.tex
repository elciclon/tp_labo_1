\section*{Introducción}
El objetivo del presente trabajo es clarificar si existe cierta relación entre las enfermedades que llevan a la muerte, variables
demográficas y de acceso a la salud, y si hubo variaciones a lo largo del tiempo. Para abordar el desafío tendremos que sanear la información provista que presenta inconvenientes tales como tablas anidadas, encabezados dentro de las tuplas, inconsistencias e información innecesaria. Tendremos que relacionar toda la información confeccionando un Diagrama Entidad Relación para, a partir del mismo crear un Modelo Relacional. Este modelo relacional será el insumo para crear una base de datos relacional, la cual será la herramienta de consulta que utilizaremos para abordar el objeto de estudio, y las preguntas que se desprenden del mismo. Utilizaremos recursos técnicos como Python, con sus módulos pandas, numpy y duckdb para modelar la base datos. Para las consultas a dicha base utilizaremos SQL, y para graficar los módulos de Python matplotlib y seaborn. El presente informe continúa con una sección "Procesamiento de Datos" donde explicaremos la metodología utilizada para sanear y consolidar la información. Un apartado "Decisiones tomadas" donde documentaremos el criterio que utilizamos a la hora de resolver situaciones surgidas de la problemática. En la sección "Análisis de Datos" responderemos las preguntas consignadas por los docentes. Y para finalizar una sección con las conclusiones que se desprenden del presente trabajo.

\subsection*{Calidad de datos}
La tabla \textbf{Defunciones} tiene valores NaN en las columnas:
\begin{itemize}
	\item jurisdicion\_residencia\_nombre
	\item muerte\_materna\_id
	\item muerte\_materna\_clasificacion
	\item cie10\_clasificacion	
\end{itemize}
 El \textbf{atributo de calidad} afectado es el de \textbf{Completitud}, no están presentes todos los valores para representar la realidad. Se trata de un problema asociado a \textbf{errores de Software}, datos obligatorios que no se asumen como tales y por lo tanto no se cargan. 
 \newline
\newline
 Utilizando la técnica GQM podemos cuantificar la magnitud del problema:
 \newline
 \textbf{Objetivo:} El dato correspondiente al nombre de la jurisdicción donde ocurrió el fallecimiento está completo
 \newline
 \textbf{Pregunta:} Cuál es la proporción de defunciones que tienen el dato correspondiente a jurisdiccion\_residencia\_nombre con valores NaN?
 \newline
 \textbf{Métrica:} \[
 \text{Métrica Nan} = \frac{\text{cantidad de defunciones con el campo \texttt{jurisdicion\_residencia\_nombre} como NaN}}{\text{cantidad total de defunciones}}
 \]
 \text{Métrica Nan} = 0.006
 \newline
 \newline
 \textbf{Objetivo:} El dato correspondiente a la causa del fallecimiento está completo
 \newline
 \textbf{Pregunta:} Cuál es la proporción de defunciones que tienen el dato correspondiente a cie10\_clasificacion con valores NaN?
 \newline
 \textbf{Métrica:} \[
 \text{Métrica Nan causa} = \frac{\text{cantidad de defunciones con el campo \texttt{cie10\_clasificacion} como NaN}}{\text{cantidad total de defunciones}}
 \]
 \text{Métrica Nan causa} = 0.002
 \newline
 
 \qquad Claramente se trata de un caso de falta de rigor en la carga de datos. Al ser ambos porcentajes menores al 1\% de la cantidad total de tuplas, decidimos descartarlos del cuerpo de datos a procesar. Las columnas relacionadas a la muerte materna no eran relevantes para este trabajo por lo cual lo más conveninente fue eliminarlas. 
 \newline
 \newline La tabla \textbf{Instituciones} tiene registros mal cargados en la columna \textbf{id\_provincia}
 \newline El \textbf{atributo de calidad} afectado es el de la \textbf{Consistencia}, hay contradicciones entre distintos datos almacenados. Se trata de un problema asociado a \textbf{errores de Software}, probablemente un problema de interface poco amigable. 
 \newline
 \newline
 Utilizando la técnica GQM podemos cuantificar la magnitud del problema:
 \newline
 \textbf{Objetivo:} El dato correspondiente al atributo id\_provincia se corresponde a una única provincia por cada id suministrado
 \newline
 \textbf{Pregunta:} Cuál es la proporción de id's incorrectamente cargados?
 \newline
 \textbf{Métrica:} \[
 \text{Métrica registros} = \frac{\text{cantidad de registros mal cargados}}{\text{cantidad total de instituciones}}
 \]
 \text{Métrica registros} = 0.0001
 
 
 \qquad Se trata de un caso donde una interface mal diseñada no muestra un desplegable que para cada provincia asigne el Id correspondiente. El ratio es insignificante por lo cual la solución más razonable era eliminar los registros erróneos.
